## 🎯 Quick Overview

### The Concept
Transform your portfolio into a **Warcraft III/DOTA 1-inspired RTS game** with Filipino cultural elements.

**Player Experience**:
- You are a recruiter/visitor exploring the land of Azgardia (Pilipinas)
- Command hero units representing Melvin's skills
- "Conquer" towers and obelisks to unlock portfolio content
- Real-time strategy controls (DOTA-style)

### Key Features

1. **Hero Units** - Represent skill domains (Frontend, Backend, DevOps, etc.)
2. **Skill Tree** - Tech stack as DOTA-style abilities (Q/W/E/R)
3. **Quest System** - Projects and experience as missions
4. **RTS Controls** - Edge-scrolling camera, right-click move, hotkeys
5. **Filipino Flavor** - Baybayin, sarimanok, fiesta themes, local landmarks
